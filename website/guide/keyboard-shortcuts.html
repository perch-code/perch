Customizing keybindings

Open Settings → Keyboard shortcuts to change a shortcut. To assign several keys to one action, edit [keybindings] in config.toml. Use the action ID from the tables below. A string assigns one key, a list assigns several, and "" or [] clears them. Your assignment replaces all defaults for that action.

[keybindings]
go_to_file = "super+t"          # Go to File on Cmd-T, and no longer on Cmd-P
pin = ""                        # no key; [] does the same
refresh = ["super+r", "f5"]     # two keys for one action
toggle_sidebar = 'super+\'     # a backslash in single quotes, or "super+\\"

Join the modifiers and the key with +. Capitalization doesn’t matter.

  • Modifiers: super (also cmd, command or meta), ctrl (or control), alt (or option) and shift. super is the command key: Cmd on macOS, Ctrl elsewhere, so off macOS ctrl+p and super+p are the same key.
  • Keys: a letter, a digit, punctuation as a US keyboard has it ([ ] \ / , . ; ' = - `), enter, escape, tab, space, backspace, delete, up, down, left, right, pageup, pagedown, home, end, f1 to f20, or a key's code as floem names it, such as KeyH or NumpadEnter. Keys are physical: shift+] is the key a US keyboard writes } with, wherever your layout puts it.
  • A backslash is an escape in a TOML string in double quotes, so write super+\ as "super+\\", or as 'super+\' in single quotes. "super+\" leaves the string open, and Perch can't read any of config.toml then.

Modifiers must match exactly. For example, super+g does not match Cmd-Shift-G. Perch reports unknown action IDs or invalid keys and applies the other entries.

A printable shortcut without Cmd, Ctrl, or Alt works only outside text fields. For example, / focuses sidebar search while reading a PR, but types a slash when you’re writing a comment.

Settings flags shortcuts that compete in the same place. Some can share a key. For example, super+g adds a suggestion while composing a line comment and finds the next match in the editor. Window actions such as New Work, Close, Go to File, and Toggle Files also work inside a message box and take priority there.

Menus and tooltips show the first shortcut assigned to an action. On macOS, the application menu displays the first shortcut for New Window, Open…, and Settings… unless it’s a plain typing key. Additional bindings still work in the window.

These stay as they are: Escape, Enter, the arrows and Tab inside menus, Go to File, pickers, dialogs and the find bar; the text keys of boxes and the editor, Cmd-C, Cmd-A and the like; Cmd-Enter, which sends or submits; Cmd-click on a symbol; the mouse's back and forward buttons; the single letters of an open item menu; and the keys macOS keeps, Cmd-Q, Cmd-H, Cmd-Opt-H, Cmd-M, Cmd-` and Cmd-Tab. Settings won't take these macOS keys for an action. An action given Cmd-Q, Cmd-H, Cmd-Opt-H or Cmd-Tab by hand never runs, as macOS has them first, and Settings says so on its row.

In Settings, click an action’s shortcut (or focus it and press Enter or Space), then press the new key. Escape cancels. Click × to clear all bindings for that action or the reset arrow to restore its defaults. Use the configuration file if you want several bindings for one action.

Hold Command on macOS or Ctrl on Linux to see shortcuts on the sidebar and view tabs and on toolbar buttons. Narrow toolbars hide hints when space is tight. Custom shortcuts take priority over the default Inbox, Worktrees, and Browse keys.
