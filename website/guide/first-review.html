Field guide / Review a change

Review your first pull request

Read the discussion, follow a changed function to its callers, and decide what feedback to send the author.

Open a pull request

Open a pull request from your Inbox. If it’s empty, select your repository under Browse (Cmd-4), or press Cmd-O and enter a PR URL or number.

Start in Conversation. Read the description and recent comments to see what the author changed and what reviewers have already covered.

Switch to Code

Click Code in the top bar, or press Cmd-Shift-2 (Ctrl-Shift-2 on Linux). Choose a changed file from the tree on the right. To open any file on the branch, press Cmd-P.

Follow a symbol

Hover over a name in the code to see its signature and documentation. To see where a changed function is used, choose Show Call Hierarchy from its right-click menu.

ActionKey
Go to DefinitionCmd-click or F12
Go to ImplementationsCmd-F12
Find All ReferencesShift-F12
Show Call HierarchyShift-Alt-H
Back, ForwardCtrl--, Ctrl-Shift--

Perch opens a single match immediately. For several matches, choose one in the panel below the editor. Definitions in a dependency or the standard library open in a read-only tab. A label such as tokio 1.40.0 tells you which version you’re reading. See Code navigation for more shortcuts.

If nothing opensCheck the status bar. Try Go to Definition again to install a missing language server or choose Trust and start if you trust the checkout.

Ask an agent on the line (optional)

Sign in to a supported agent. Click + beside a line, or select Ask about this on a GitHub comment. Pick a model from the dropdown and ask your question. You can choose a different model for your next reply in the same thread. See Agent sandbox and approvals for what the agent can access.

Post your review

To leave a line comment for the author, choose GitHub in the dropdown. Perch marks it Draft and saves it locally, even offline or across restarts.

Click Review to check your drafts, choose a verdict, and submit them to GitHub together. You can also ask agents to review the diff before posting. See Posting and drafts for suggestions and replies.
