Field guide / Review a change

Review your first pull request

Read the discussion, follow a changed function to its callers, and decide what feedback to send the author.

Open a pull request

Open a pull request from your Inbox. If it’s empty, select your repository under Browse (Ctrl-3), or press Cmd-O and enter a PR URL or number.

In Conversation, read the description and recent comments.

Switch to Code

Click Code and pick a changed file. Press Cmd-P to open any file on the branch.

Follow a symbol

Hover over a name in the code to see its signature and documentation. To see where a changed function is used, choose Show Call Hierarchy from its right-click menu.

Expand a caller in the panel below the diff, or switch to Callees. Go to Definition (F12) also works in dependencies. See Code navigation for references, implementations, and the full shortcut list.

If nothing opensCheck the status bar. Try Go to Definition again to install a missing language server or choose Trust and start if you trust the checkout.

Ask an agent on the line (optional)

Click + beside a line or Ask about this on a comment. Choose a signed-in agent and ask your question.

Post your review

To leave a line comment for the author, choose GitHub in the dropdown. Perch marks it Draft and saves it locally, even offline or across restarts.

Click Review to check your drafts, choose a verdict, and submit them to GitHub together. You can also ask agents to review the diff before posting. See Posting and drafts for suggestions and replies.
